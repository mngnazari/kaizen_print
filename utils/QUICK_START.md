## ویندوز 🪟

### گام 1: قرار دادن فایل‌ها
فایل‌های اصلی و پردازش شده رو در یک پوشه قرار بده.

### گام 2: اجرای اسکریپت
فایل `generate_mapping.bat` رو دابل کلیک کن.

### گام 3: دریافت mapping.txt
فایل `mapping.txt` تولید شده رو به بات بفرست.

---

## لینوکس / مک 🐧🍎

### گام 1: قرار دادن فایل‌ها
فایل‌های اصلی و پردازش شده رو در یک پوشه قرار بده.

### گام 2: باز کردن ترمینال
```bash
cd /path/to/your/files
```

### گام 3: اجرای اسکریپت
```bash
bash /path/to/utils/generate_mapping.sh
```

یا:
```bash
python3 /path/to/utils/mapping_generator.py
```

### گام 4: دریافت mapping.txt
فایل `mapping.txt` تولید شده رو به بات بفرست.

## 📝 قوانین نام‌گذاری (مهم!)

### ✅ **درست:**

**تبدیل فرمت:**
```
model.3dm (اصلی) → model.stl (جدید)
```

**تقسیم فایل:**
```
bigpart.stl (اصلی) → bigpart#1.stl, bigpart#2.stl, bigpart#3.stl
```

**بدون تغییر:**
```
ready.stl (اصلی) → ready.stl (همون)
```

### ❌ **اشتباه:**

```
model_new.stl     # ❌ باید model.stl باشه
part_1.stl        # ❌ باید part#1.stl باشه (با #)
bigpart-1.stl     # ❌ باید bigpart#1.stl باشه (با #)
Part#1.stl        # ❌ حروف باید کوچک باشن
```

---

## 📦 فایل‌هایی که باید بفرستی

بعد از ارسال `mapping.txt`، برای هر فایل باید بفرستی:

1. **فایل STL** (اگه تغییر کرده یا تقسیم شده)
2. **عکس JPG** (همیشه - پیش‌نمایش)
3. **فایل ZIP** (همیشه - فایل اصلی)

**مثال:**
اگه `model.3dm: model.stl` داری، باید بفرستی:
- `model.stl`
- `model.jpg`
- `model.zip`

## ❓ سوالات سریع

**Q: چطوری فایل ZIP رو درست کنم؟**
A: فایل اصلی رو zip کن با همون اسم فایل پردازش شده.

**Q: عکس JPG از کجا بیارم؟**
A: Screenshot از نرم‌افزار 3D بگیر و ذخیره کن.

**Q: اگه اشتباه شد چی؟**
A: فایل `mapping.txt` رو دستی ویرایش کن یا دوباره اسکریپت رو اجرا کن.
